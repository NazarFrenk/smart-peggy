# Smart Peggy
Smart BLE-controlled model lighthouse project. Features ESP32 firmware for addressable LEDs and custom lighting effects, integrated with a cross-platform Qt/QML mobile application.

Smart Peggy — декоративная модель маяка с управлением освещением через мобильное приложение и питанием от литий-ионных аккумуляторов с возможностью скрытого подключения к сети.

## Что описано в документации
- Внешний вид модели: круглая форма с белыми стенами и красным фундаментом.
- Детали: арочные двери и окна, козырёк, гладкие поверхности.
- Управление светом: BLE-соединение с ESP32, мобильное приложение Smart Peggy, режимы подсветки и яркость.
- Питание: четыре литий-ионных аккумулятора и скрытый разъём для сети.
- Роадмап: постепенное достижение MVP от работоспособного прототипа до завершённого дизайна.

## Мобильное приложение
- Название приложения: Smart Peggy.
- Тип: мобильное приложение для управления освещением изделия.
- Связь: BLE с ESP32.
- Функции:
  - подключение к ESP32 и подтверждение связи;
  - регулировка яркости подсветки;
  - выбор режимов подсветки;
  - управление состоянием режимов (включение/выключение, переключение между режимами).
- Интерфейс: понятный, интуитивный, не перегруженный техническими терминами.

## Питание
- Основное питание: четыре литий-ионных аккумулятора.
- Источник стационарного питания: возможность работы от сети через скрытый разъём для шнура с вилкой.
- Требование: разъём должен располагаться в скрытом месте, чтобы не портить внешний вид модели.
- Управление питанием: переключение между батареями и сетевым питанием должно быть безопасным и надёжным.
